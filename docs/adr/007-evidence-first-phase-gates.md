# ADR 007 — Evidence-first phase gates and publication path

Date: 2026-09-06

Status: Accepted

## Context

The documentation audit found a research repository described as a finished
platform, obsolete setup instructions and stronger conclusions than its archive
supports. Statistical analysis appeared late in the plan. The graph construction
has no code/decoder yet, and a direct full-size quantum product needs a budget.
The owner requested a line-by-line Markdown audit and a phased direction update.

## Decision

Keep README research Stages 1–3 and roadmap Phases 0–6. Reopen Phase 1 evidence
and reproducibility gates; sequence Phase 2 through classical decoding to
feasible qLDPC; extract an engine after demonstrated reuse. Require statistics
from the first study. Make publication conditional, potentially before the platform.

Preserve measured JSON, historical sessions and ADR bodies. Correct live prose
and add dated historical amendments. Distinguish numerical checks from proof
and immutable input data from unchecked AI narration.

## Consequences

P1-R1 archive protection/semantic validation is the next code milestone. This
documentation revision does not close code gates, repair WSL2, authorize cloud
spending or submit a paper. ROCm remains Phase 4 per ADR 006. Novelty and
platform maturity must be demonstrated rather than promised.
